## 🔬 Compétences techniques clés

### Architecture & Qualité
- **Clean Architecture** (Domain / Data / Presentation), User-Type-First
- **Patterns** : Repository, Use Cases, Provider/Notifier, Either (gestion d'erreurs fonctionnelle)
- **Multi-tenant** : isolation stricte des données par entité (vendeur, client)
- **Offline-first** : Drift (SQLite), synchronisation bidirectionnelle

### Fiabilité & Sécurité
- **Idempotence** : clés anti-double-débit, contraintes `UNIQUE`, transactions **ACID**
- **UUID v7** : identifiants time-ordered pour indexation optimisée
- **Upload sécurisé** : URLs présignées **AWS SigV4**, contrôle de validation serveur
- **2FA**, règles de sécurité Firestore/Storage, gestion des secrets (env)

### Backend & Infrastructure
- **Serverpod** (backend Dart), **PostgreSQL / Neon**, **Cloudflare R2** (0 $ de bande passante)
- **Firebase** (Auth, FCM, Analytics, Crashlytics, Remote Config)
- **CI/CD** : GitHub Actions (analyse, tests, build APK automatique)
- **NestJS / FastAPI / Supabase** pour les services B2B & SaaS

### Mobile avancé
- Paiement **Mobile Money** (Orange Money, Moov, Wave)
- **Impression thermique** (Sunmi SDK), **QR code** (scan + génération), cartographie
- **2FA**, biométrie (local_auth), ML on-device (ML Kit), voice-to-text
- Go Router, animations & micro-interactions, responsive multi-plateforme

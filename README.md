## 🔬 Compétences techniques clés

### Architecture Logicielle (Niveau Industriel)
- **Domain-Driven Design (DDD)** : Aggregates, Bounded Contexts (13+ domaines), Value Objects, Domain Events, Rich Models
- **CQRS** : Séparation stricte Command Side (writes) / Query Side (read-model projections)
- **Event Sourcing** : `CanonicalEventEnvelope` avec SemVer, JSON Schema validation, temporal ordering, append-only event store
- **Clean Architecture** : Ports & Adapters (Protocol classes), dépendance inversée, séparation Domaine/Infrastructure
- **Transactional Outbox** : Écriture atomique événements + business dans la même transaction, zéro perte
- **Idempotence Stricte** : Clés anti-double-exécution, `UNIQUE` constraints, transactions ACID

### Design System & UX Professionnelle
- **MDI Workbench** (VS Code-inspired) : 7 Parts contractuelles — Titlebar, Activitybar, Sidebar/Explorer, Editor Tabs (MDI), Auxiliary Inspector, Panel, Statusbar
- **Design System Flat Pro** : Haute densité, hairlines 1px, typographie monospace JetBrains Mono pour données financières
- **Command Palette universelle** (`Ctrl+K`) : Recherche floue de produits, clients et actions
- **No Modal by Default** : Règle des 6 niveaux d'interaction (Inline → Auxiliary → Editor → Panel → Overlay → Dialog)
- **Responsive** : Grille adaptative Desktop ≥1200px / Compact 900-1199px / Tablette 600-899px / Mobile <600px

### Sécurité & Audit
- **RBAC + ABAC** : Rôles (PATRON, VENDEUR, CAISSIER) + politiques d'attributs dynamiques évaluées par moteur Google CEL
- **Step-Up Authorization** : Override par PIN superviseur (PBKDF2/HMAC), jeton non-rejouable à durée limitée
- **Audit Trail immuable** : Chaîne de hachage SHA-256 append-only, détection de falsification en base
- **Crypto-Shredding GDPR** : Anonymisation par destruction de clé symétrique sans briser la chaîne d'audit
- **Dual Custody** : Approbation multi-acteurs pour opérations sensibles

### Offline-First & Résilience
- **Local Outbox** : SQLite chiffré côté client, synchronisation delta batch dès reconnexion
- **Baux Cryptographiques** : Authority Leases (JWS tokens) pour autorisation hors-ligne avec expiration et révocation
- **Zero-LWW** : Jamais de résolution par timestamp seul ; Three-Way Merge et Commutative Delta
- **Chaos Engineering** : 15 types de fautes (network blackout, disk full, OOM, clock drift), steady-state hypothesis

### Fiabilité Financière
- **DecimalPolicy Stricte** : 0% float/double dans le cœur financier ; typologie sémantique (Money, UnitPrice, Quantity, TaxRate…)
- **UUIDv7** : Identifiants time-ordered RFC 9562 pour indexation optimisée
- **Double-Entry Accounting** : Écritures comptables équilibrées (Débit = Crédit) avec period close
- **Moteur de Pricing 5-Cascade** : Base → Accords B2B → Volumes → Promotions (AST) → Coupons, avec floor price

### Plateforme Modulaire
- **Platform / Domain Separation** : Workbench Shell agnostique métier, Domain Packs extensibles
- **Extension Registry** : Contrats versionnés (Contexts, Commands, Auxiliary Views, Agent Skills)
- **Contract-First Modules** : Modules métier ne couplent jamais leurs implémentations internes
- **Intent-Only Navigation** : Zéro `Navigator.push()` ; tout passe par `NavigationIntent` → `ContextOrchestrator`

### Agentique & IA
- **Agentic Workbench** : Agent en tant que Context Producer (pas un chatbot décoratif)
- **Niveaux d'autonomie** : L0 Explain → L1 Navigate → L2 Propose → L3 Execute w/ Approval → L4 Autonomous
- **Proposal Before Mutation** : Preview vérifiable avant toute mutation destructrice
- **GenUI / A2UI** : Génération dynamique de surfaces métier par l'agent dans le TabManager

### Backend
- **FastAPI** async avec Pydantic v2, Uvicorn, CORS, OpenTelemetry-compatible tracing
- **PostgreSQL 16** avec Row-Level Security (RLS), indexation B-Tree & GIN
- **SQLAlchemy 2.0** pour projections read-model
- **WebSocket** temps réel pour synchronisation multi-caisses
- **Celery** workers pour PDF, WhatsApp, rapports asynchrones

### Frontend
- **Flutter Desktop** (Linux/Windows) + Mobile responsive
- **Riverpod** state management (ProviderContainer, StateNotifier)
- **WorkbenchShell** : MDI tabs persistants, dirty state `●`, restauration après crash
- **BarcodeScannerInterceptor** : Détection HID par vélocité de frappe (>8 caractères / <20ms)
- **PDF** génération + **impression thermique** ESC/POS
- **QR code** (scan + génération), **fl_chart** dashboards

### DevOps & Distribution
- **GitHub Actions** : lint (Ruff) → tests (pytest) → build (Flutter + PyInstaller) → Inno Setup installer → GitHub Release
- **PyInstaller** : Backend packaging en `.exe` standalone
- **Inno Setup** : Installateurs Windows (Server + Client variants)
- **NSSM** : Backend en service Windows managé
- **SHA256 checksums** pour intégrité des artefacts
